# Laboratorios Interactivos de Geometría y Trigonometría 📐

Aplicaciones web interactivas basadas en código para la enseñanza de matemáticas, geometría analítica y trigonometría, impulsadas por Python.

## 🚀 Descripción General
Este repositorio contiene una colección de laboratorios virtuales diseñados para estudiantes de bachillerato. Su objetivo es hacer que el aprendizaje de las matemáticas sea visual, interactivo y aplicado a problemas físicos del mundo real (tecnología, deportes, arquitectura).

## 🛠️ Requisitos y Tecnologías
- **Lenguaje:** Python 3.8 o superior
- **Librerías principales:** `streamlit`, `plotly`, `numpy`
- **Entorno:** Visual Studio Code (recomendado) o cualquier navegador web moderno.
